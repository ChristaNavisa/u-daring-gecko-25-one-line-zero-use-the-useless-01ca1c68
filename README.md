Entry for the make.fun bounty [One Line, Zero Use: The Useless Superpower Sprint](https://make.fun/c/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68).

`main.ts` writes a single original one-liner — at most 200 characters — describing a hilariously useless superpower to `/output/entry.txt`. Nothing else is submitted.

Run it with Node 22 or later:

```sh
node main.ts
```
